# Mografy Templates

Free, ready-made templates for product demo videos, all in English. Portrait templates (9:16) share an editorial look, a
white printed page with tall Anton headlines and one orange accent, for Threads, Reels and Shorts. Landscape templates
(16:9, ids ending in `-wide`) share the look of the Mografy montage film, night grounds, spectrum light and
kinetic type, for landing pages, YouTube and decks. Browse them at
[mografy.app/docs/templates](https://www.mografy.app/en/docs/templates).

```sh
mografy add hook-impact three-steps cta-endcard projects/my-film
```

A folder that is not a project yet becomes one, with a scene that plays the templates in order.

- `<id>.ts`: one template, a complete scene module (`template`, `meta`, `params`, `renderFrame`).
- `kit.ts`: what every template shares: the stage, safe areas, cursor, envelopes and `play` for using a template inside a film.
- `editorial.ts`: the 9:16 look (page, header and footer rules, letter-by-letter Anton lines, underline, sweep,
  picture windows, carousel).
- `montage.ts`: the 16:9 look (grounds, kinetic type, spectrum, comets and rims, glass pills, product windows on
  tilted planes).
- `fonts/`: Inter 500–800 Latin subsets (SIL OFL 1.1) and Anton (SIL OFL 1.1).
- `catalog.json`: generated by `pnpm templates:sync`; read by `mografy add`, the Skill reference and the website.

How to use and edit templates: [references/templates.md](../.agents/skills/mografy/references/templates.md).

## Adding a template

1. Write `templates/<id>.ts` from an existing template of the same aspect. Landscape ids, and only they, end in `-wide`; the
   two ratios of one template point at each other with `pair`. Copy is English, defaults use the fictional product
   Northwind.
2. `pnpm templates:preview <id>` (and `--theme=dark`, or another ground for 16:9) builds `projects/_templates/<id>` with output
   glow and grain off, runs `mografy check` and `mografy review`; look at the stills.
3. `pnpm templates:typecheck`, then `pnpm templates:sync` to update `catalog.json` and the Skill reference.
4. For the website: `pnpm templates:media <dir> <id...|all>`, then in the website repository
   `node scripts/import-templates.mjs <mografy-checkout> <dir>`.
